# ReEscape Protocol

基于 OneBot WebSocket 的可扩展聊天机器人运行时。

ReEscape Protocol 将消息接入、会话状态、长期记忆、ReAct 工具调用、自然调度和管理后台拆分为清晰的边界，适合自托管和二次开发。

## 主要能力

- OneBot WebSocket 消息收发与断线重连
- 按用户和会话隔离的上下文、长期记忆与状态
- ReAct Agent 与可配置工具、Skills
- AI profile、Character Card 和运行时配置热更新
- 管理后台、健康检查、就绪检查和 Prometheus 指标
